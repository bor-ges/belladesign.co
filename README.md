# Bella Design

Landing page de portfólio (HTML + Tailwind via CDN + GSAP), com nome reativo ao cursor, cursor customizado e portfólio filtrável.

## Como ver
Abra `index.html` no navegador (ou use a extensão Live Server do VS Code).

## Capas do Behance
Rode `python3 fetch-covers.py` na pasta do projeto, ou salve manualmente em `img/covers/`
como `zago.jpg`, `revista.jpg`, `rayane.jpg`, `rpg.jpg`, `prata.jpg`, `guara.jpg`, `solaris.jpg`, `sonhar.jpg` e `netinho.jpg`.

## Pendências de conteúdo
- E-mail de contato e link do Behance (seção Contato em `index.html`)
- Depoimentos (placeholders)
